# Requisitos: Fundação institucional

## Escopo

- Criar uma página inicial institucional para apresentar a escola.
- Estabelecer identidade visual consistente e responsiva.
- Preparar a estrutura de navegação para futuras áreas de cursos e notícias.
- Atender a missão de ajudar futuros alunos a descobrir e escolher cursos técnicos.

## Decisões

- Frontend em React com Vite e TypeScript.
- Estrutura modular que permita adicionar catálogo e notícias incrementalmente.
- Experiência adaptável a dispositivos móveis e navegadores modernos.
- Esta fase estabelece a base institucional; catálogo, login editorial e gestão de notícias ficam para fases posteriores.

## Contexto

A fase corresponde à F01 — Fundação institucional do roadmap. A missão prioriza informações claras, confiáveis e acessíveis para futuros alunos. A stack de referência define TypeScript, React com Vite, Node.js com Express e SQLite inicial. A fundação não precisa implementar ainda o backend ou persistência.
