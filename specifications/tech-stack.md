# Stack técnica

- **Linguagem:** TypeScript no frontend e no backend.
- **Frontend:** React com Vite.
- **Backend:** Node.js com Express.
- **Banco de dados:** SQLite na fase inicial.
- **Experiência:** layout responsivo e compatível com navegadores modernos.
- **Acesso editorial:** login para a equipe cadastrar notícias exibidas na página inicial.

As matrizes curriculares devem corresponder aos cursos técnicos indicados pela coordenação. Disciplinas mock podem ser usadas temporariamente quando necessário.
